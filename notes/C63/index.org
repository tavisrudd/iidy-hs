Rust iidy (=~/src/iidy=) has no =c= setup and is read-only from this repo,
so its follow-ups are tracked here (as C57 is for local-time timestamps).
On 2026-11-20 iidy-hs changed three behaviours that Rust shares:

1. Global SSM config (C55). Rust calls =apply_global_configuration= on every
   stack-args load (=src/cfn/stack_args.rs:325-327=, with a
   "TODO disable behind feature flag"). iidy-hs reads =/iidy/= only with
   =--global-config=, because CloudFormation operator roles without SSM read
   printed an AccessDenied warning on every run.
2. YAML 1.1 booleans (C62). Rust converts yes/no/on/off strings after
   preprocessing (=convert_yaml_12_to_11_compatibility_with_context=,
   =src/yaml/engine.rs:461-551=), so a quoted ="yes"= and strings built
   during preprocessing become booleans, softened by path and length
   heuristics (=should_preserve_as_string=). iidy-hs now reads YAML 1.1
   booleans at parse time from plain, untagged scalars only; quoted values
   stay strings and keys keep their text. Details and the full list of
   differences: =docs/dev/rust-compatibility.org= ("YAML 1.1 Booleans Read
   at Parse Time") and C62.
3. Stack-args type errors (C61). Rust deserialises with
   =serde_yaml::from_value= (=src/cfn/stack_args.rs:323=), giving
   =invalid type: boolean `false`, expected a string= with no field or key
   (as reported). iidy-hs reports
   =invalid type for Parameters.PublicFavicon: expected a string, got boolean `false`=.

4. Stack-args are YAML 1.2 (C64, decided 2026-11-20): iidy-js had no YAML
   1.1 mode (js-yaml 3.14.1 core-schema booleans only; see C62 "Comparison
   with iidy-js"), so plain yes/no/on/off in stack-args were strings. Only
   CloudFormation templates are YAML 1.1. Rust reads stack-args with
   =YamlSpec::V11= (=src/cfn/stack_args.rs:195=) and rejects e.g.
   =Parameters: {Flag: yes}=.

Status and polling (C58-C60) need nothing in Rust: those were iidy-hs
divergences from Rust, which already handles the cleanup statuses, filters
poll events by start time and colours rollback-complete green.
