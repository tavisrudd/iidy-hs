lines 859-861) is =pure $ fromValue $ astToValueRaw contentAst=: it builds

=Value= through =astToValueRaw= (line 913), whose objects are sorted, and
converts back. [[file:../C8/index.org][C8]] added =astToOValueRaw= and moved
=!$parseYaml= (line 841) onto it, and left =resolveEscape= as a one-line
follow-up (C8 task note and review). The expected fix is
=resolveEscape _ctx _meta (EscapeTag contentAst) = pure (astToOValueRaw
contentAst)=; the existing escape tests (=test/Test/ResolverTest.hs= around
line 916) cover scalars only. Duplicate keys already behave as Rust's
=Mapping= insert: first position, last value.
