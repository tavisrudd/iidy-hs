# Handoffs (archived)

These are the Markdown handoff documents iidy-hs used to scope and record
work from February to March 2026, before the project moved to `c` cards
(card C1, November 2026). They are history only: nothing here is live work,
and new handoffs are not written.

- `done/` holds handoffs that were completed at the time.
- The top-level files were open, paused or finished-but-not-moved when the
  project switched over. Card C2 triaged every open item in them against the
  code; see `notes/C2/report--handoff-triage.org` for what became a card and
  what was dropped.

For current work, run `c next` and see `AGENTS.md`.
