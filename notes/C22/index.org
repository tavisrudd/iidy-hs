   operations, run nothing; (b) implement as Rust does. Recommendation: (a)

   silent skip of a pre-deploy command (a build, a check, an upload) is

   compiled in only with the cargo feature =debug-logging= (=Cargo.toml:17=,
   =src/debug.rs=) and =env_logger= follows =RUST_LOG= (=src/main.rs:265=).
   So Rust already accepts and ignores it. Choices: (a) keep accepting it,
   keep the Rust help text, and say in =docs/command-reference.org=,

   shared behaviour, not a divergence) that it has no effect yet; (b)

   is the parity answer, scripts that pass =--debug= to either original

   Rust).
