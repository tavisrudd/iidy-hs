Rust iidy (=~/src/iidy=, read-only from this repo) formats all
interactive timestamps in UTC: =render_timestamp(&self, dt: &DateTime<Utc>)=
in =src/output/renderers/interactive.rs= uses
=dt.format("%a %b %d %Y %H:%M:%S")= with no zone conversion or label.
iidy-js shows local time (=dateformat(ts)= in =src/cfn/formatting.ts:14=),
and iidy-hs now does too (C56). This card records the matching change for
the Rust side; it has no =c= setup, so it is tracked here.

Work happens in =~/src/iidy=, by whoever owns that repo; nothing in
iidy-hs changes. Gate: =render_timestamp= converts with
=dt.with_timezone(&chrono::Local)= before formatting, Rust snapshot tests pin
a zone (for example =TZ=UTC=) so they stay stable, and the divergence entry
in =docs/dev/rust-compatibility.org= is removed once both ports agree.
