=iidy demo= runs the shell commands of a demo script and rewrites each
=iidy= command so it runs the current binary, adding =--no-remote-imports=
(and, after [[file:../C15/index.org][C15]], one =--trust-import-source=
per trusted prefix) so the commands inherit the demo's import policy. When
the current binary is the =iidy= found on =PATH= (=getIidyExe= in
=src/Iidy/Demo.hs= returns =Nothing=), =substituteIidyCommand= leaves the
command untouched, so the flags are dropped and the commands run with
remote imports allowed and no trusted prefixes: =--no-remote-imports=
fails open. Rust (=~/src/iidy/src/demo.rs:93-112=) skips substitution the
same way. Found by the C15 re-review.
