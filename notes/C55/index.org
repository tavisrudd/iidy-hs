CloudFormation operator roles used with iidy-hs often lack SSM read access
to =/iidy/=, so every stack operation printed
"Warning: failed to load global config from SSM: AWS SSM error AccessDenied".
Rust iidy always reads =/iidy/= (=src/cfn/stack_args.rs=); this card makes
the Haskell port read it only on request.
