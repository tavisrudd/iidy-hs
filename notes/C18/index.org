Decision (Tavis, 2026-11-16): accept the proposed escaping defaults below
as written.

Settled by this card (confirmed by Tavis 2026-11-16; the worker follows
these and asks about anything else that changes what the user sees):
- Visible form: every escaped character becomes =\uNNNN= in four lower-case
  hex digits (=ESC= is =\u001b=), the same spelling Rust's YAML emitter
  uses for control characters (=~/src/iidy/src/yaml/emitter.rs:475=).
- Escaped: C0 controls except =\n= and =\t=, DEL, C1 controls
  (U+0080-U+009F), U+2028 and U+2029, and the bidirectional controls
  U+202A-U+202E and U+2066-U+2069 (a reordered line can disguise an added
  diff line). A =\r= is escaped unless it is directly followed by =\n=.
- Applies to text from outside the tool (template text and diffs, AWS
  strings such as event reasons, tags, parameters, output values, stack
  names and descriptions, exception text) before the tool adds its own
  colour codes, so the tool's own colour sequences are untouched, and
  before any width or padding calculation, so columns align on the visible
  text.
- Not applied to the two deliberate document outputs, =OdRawOutput= and
  the body of =OdStackTemplate= (what =render=, =get-import= and
  =get-stack-template= print for redirecting into files): their bytes stay
  exact.
