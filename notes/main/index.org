Cards live at =notes/C<ID>/index.org=. =next/C<ID>= links open TODO, NEXT
and WAITING work; =active/C<ID>= links STARTED work. Change state only with
=c set=; DONE and CANCELLED cards have no status link.

This lane uses card-owned scheduling (SCHEDULING_SCHEMA=1): priority,
prerequisites and groups belong to each card. =archive-log.org= receives one
completion line from each =c set ID done --note RESULT=.
