approval checks; =template-approval review= shows a diff of it and then
approves. Nothing checks that the pending bytes hash to the key's name, or
that the bytes approved are the bytes that were shown. This changes the
approval workflow (the trust model), so it starts with a design note for
Tavis, as C16 did.
