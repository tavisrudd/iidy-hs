A stack-args file can compute its =Profile=, =Region= and =AssumeRoleARN=
from imports. The deploy commands build a first AWS environment from those
fields before preprocessing the file (=src/Iidy/Cfn/Runner.hs= around lines
64-70, =src/Iidy/StackArgsLoader.hs= around lines 197-207), so imports in
the stack-args file run under the ambient credentials and region rather
than the ones the file finally names, silently. See
[[id:org:01a1e68e-1585-707c-91d5-94cc843d0bd6][Medium: stack-args imports can run under different credentials]].
