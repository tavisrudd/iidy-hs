Found by the Opus review of [[file:../C20/index.org][C20]] (2026-11-17).
C20 caps YAML alias expansion in the parser, but =$defs= references
(=!$ name=) are expanded later, in the resolver, and amplify the same way
with no limit. A 9-line file (=a0: xxxxxxxxxx=, then =aN: [!$ aN-1 x10]= for
N = 1..6, =out: !$ a6=) renders 25,000,005 bytes in 1.18 s at C20's tip, and
each further line multiplies output by ten. A remote import can carry it,
so it is the same denial-of-service class the C4 security review raised
(=notes/C4/report--security-review.org=). Rust has no limit either.
