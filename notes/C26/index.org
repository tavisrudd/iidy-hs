A plain imported document (one without =$imports= or =$defs=) whose body
holds a preprocessing tag that is not resolved renders as the string
='!$escaped'= in iidy-hs, while Rust keeps the tag. Found in the C15
research (=notes/C15/report--remote-template-options.org=, "Side findings",
last bullet).

Reproduced with both binaries: a file =imp.yaml= with
=plain:\n  note: !$ secret\n  n: 1= imported as =plain: imp.yaml= and read
back by =get-import imp.yaml= prints =note: !$ secret= under Rust and
=note: '!$escaped'= under iidy-hs.

Cause: plain imported YAML goes through =parseYamlContent= in
=src/Iidy/Yaml/Imports/ContentParsing.hs= (line 48), which calls
=astToValueRaw= (=src/Iidy/Yaml/Resolution/Resolver.hs= line 908). Its case
=AstPreprocessingTag _ _ -> String "!$escaped"= (line 925) throws the tag
away. Rust loads these documents with =serde_yaml::from_str=
(=~/src/iidy/src/yaml/imports/loaders/utils.rs= line 15), which keeps
the tag. The resulting type is aeson =Value=, which cannot carry a tag. The
same function already represents CloudFormation and unknown tags (lines
927-930) as a one-key object whose key is the tag name (=!Ref=, ...), and
the emitter prints a single key starting with =!= as a tag
(=isTaggedKvs=, =src/Iidy/Yaml/Emitter.hs= around line 255), so the same
convention can carry =!$= tags. Hazards: the AST has no function from a
=PreprocessingTag= constructor to its tag name and raw argument, and Rust
keeps tags with structured arguments verbatim (=a: !$map [1]= prints
as a tag with a sequence), whereas iidy-hs fails to parse malformed =!$map=
at all (a separate difference). Other callers of =astToValueRaw= share the
function: =!$escape= (line 861), =!$parseYaml= (line 842), ConvertStack
(=Cfn/Operations/ConvertStack.hs= line 193), so the change must not alter
their output unless that is intended.

Also seen in the same sample and not part of this card: iidy-hs prints the
imported mapping's keys sorted (=n= before =note=) where Rust keeps source
order; that is the key-order loss of C8 for the other =astToValueRaw=
callers.
