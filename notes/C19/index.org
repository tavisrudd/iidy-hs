Several AWS loaders turn transport errors into messages with =show=, which
includes the request headers, among them =X-Amz-Security-Token= (the
session token for temporary credentials): =src/Iidy/Yaml/Imports/Loaders/Ssm.hs=
around lines 60 and 93, and the same pattern in the S3, Cfn, Sts and
TemplateApproval code. The C4 review reproduced it with fake credentials.
See [[id:org:01a1e68e-1585-707c-91d5-94cadad6bb43][Low: AWS session token is printed in transport-error messages]].
