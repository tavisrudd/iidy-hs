The two =reliableTimeProvider= tests in =test/Test/TimingTest.hs= (around
line 168) call the real =reliableNow= in =src/Iidy/Aws/Timing.hs= (around
line 83), which resolves =pool.ntp.org= with =getAddrInfo= and sends an SNTP
query (=queryNtp=, around line 107). That is a real network call in the test
suite, against the project rule, and the =getAddrInfo= foreign call cannot
be interrupted by the 2-second =timeout= or by tasty's per-test timeout, so a
stuck resolver hangs the run. Found by [[file:../C6/index.org][C6]], which
keeps it as an open suspect for the intermittent hang.
