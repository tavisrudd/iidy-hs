[[file:../C26/index.org][C26]] made plain imported documents keep their
unresolved =!$= tags, as Rust does, by rebuilding each tag from the typed
=AstPreprocessingTag= node (=preprocessingTagParts= in
=src/Iidy/Yaml/Ast.hs=). The typed node does not keep how the tag was
written, so three spellings differ from Rust (recorded in
=DIVERGENCES.md=): aliases print under their canonical name (=!$include x=
as =!$ x=, =!$string x= as =!$toYamlString x=), a one-element sequence
argument to a single-argument tag loses its sequence (=!$not [true]= as
=!$not true=), and mapping fields print in a fixed order. Matching Rust
needs the parser (=src/Iidy/Yaml/Parser.hs=) to keep the written tag name
and argument on the node. Depends on C26 landing.
