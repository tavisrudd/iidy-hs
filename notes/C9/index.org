The output renderer's width comes from =src/Iidy/Output/Terminal.hs=
(around lines 23-34), which reads only the =COLUMNS= environment variable and
falls back to 80 columns. =COLUMNS= is usually not exported to child
processes, so in practice output wraps at 80 on wide terminals. The Rust
original queries the real terminal size (=output/terminal.rs= around line
55). The =terminal-size= package is already a dependency and is used in
=src/Iidy/Cli/Help.hs=. Flagged in the March Gemini review of the
interactive renderer; still present per the C2 triage
([[file:../C2/report--handoff-triage.org][report]]).
