Found by the C28 review ([[file:../C28/index.org][C28]], "Review
2026-11-16", pre-existing items). The YAML emitter
(=src/Iidy/Yaml/Emitter.hs=) prints the float =1.0= as =1= and =1e5= as
=100000=, so a float turns into an integer on output, and prints a string
holding a tab and the control character U+0001 as a quoted raw tab with the
U+0001 dropped, which loses data. Rust prints =1.0=, =100000.0= and
="a\tb\x01"=. Applies to every command that emits YAML (=render=,
=get-import=). Distinct from [[file:../C18/index.org][C18]], which is about
terminal output, not YAML documents.
