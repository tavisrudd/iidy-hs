The rewrite: =valueToStackArgs= runs one =FieldParser= (=ReaderT (KeyMap
Value) (Either Text)=) over the mapping. Three field combinators own the
lookup and null handling: =optionalField= (absent or null is =Nothing=,
anything else must parse), =lenientField= (a non-matching value reads as
absent) and =rawField= (=StackPolicy=, null kept). Per-type value parsers
(=strList=, =strMap=, =int=, =onFailure=, =capabilities=) share one
=typeError= for the "invalid type for KEY" texts. The do-block keeps the
error order; the lenient fields come after the checked ones and cannot
fail. =CommandsBefore= stays a plain =strList= field. The exported getters
=getStrListValidated=, =getStrMapValidated= and =getInt= keep their
signatures and run the same combinators; =getStr= stays for the loader;
=getBool=, =parseOnFailure= and =parseCapabilities= are gone (no user
outside =Fields.hs=, never re-exported by the loader).
