Peregrine (=~/src/peregrine=) runs its cards through supervised workers:
Codex sessions in tmux panes or Claude sub-agents work each card on a branch
in their own worktree, a review worker checks each branch, and a Claude Code
supervisor assigns, reviews, lands and cleans up. The contract lives in
=scripts/supervisor/= (=PROTOCOL.md= for workers, =REVIEW.md= for the
reviewer, =RUNBOOK.md= for the supervisor, plus =send.sh= and =status.sh=),
started with the =/supervise= skill, with builds serialized by
=scripts/guarded-cargo=. iidy-hs adopted =c= cards in
[[file:../C1/index.org][C1]] and now wants the same supervision. Memory on
this host is tight (Tavis, 2026-11-16: be careful with RAM), so builds by
parallel workers must be serialized.

=~/.cache/iidy-hs/build.lock=, refuses below 6 GiB available memory
(=IIDY_MIN_AVAIL_GB=), runs under =choom -n 1000=, and lets nested calls
reuse the held lock. The pre-commit hook now runs its build and tests
through it, with a 60-second per-test timeout so a C6 hang fails the commit
with a named test instead of blocking it. Checked: =scripts/guarded-build
true= succeeds; with =IIDY_MIN_AVAIL_GB=999= it refuses with exit 75.
