Rust has no working AWS imports in stack-args. =load_stack_args=
(=~/src/iidy/src/cfn/stack_args.rs:181=) preprocesses the file first
(line 199, =preprocess_yaml=), and =preprocess_yaml= builds
=ProductionImportLoader::new()= (=~/src/iidy/src/yaml/engine.rs:578=) with
no AWS configuration, so an =ssm:=, =ssm-path:=, =cfn:= or =s3:= import
fails with "AWS configuration required"
(=~/src/iidy/src/yaml/imports/loaders/mod.rs:72-93=). Only afterwards are
=Profile=, =Region= and =AssumeRoleARN= read from the preprocessed value and
the AWS configuration built (lines 215-255); the comment there, "Configure
AWS BEFORE preprocessing (enables $imports with AWS calls)", does not
describe what the code does.

iidy-hs [[file:../C17/index.org][C17]] (landed 2026-11-16) settled the
behaviour; this card ports it to Rust so both agree. The rule, from
=DIVERGENCES.md= ("Stack-args AWS imports" entry) and the C17 card:
- AWS imports in stack-args run under an AWS configuration built from
  =Profile=, =Region= and =AssumeRoleARN= as written in the file, with
  =--profile=, =--region= and =--assume-role-arn= taking precedence.
- When the file makes an AWS import, each of those fields must be absent,
  a plain string, or an environment map whose entry for the current
  environment is a plain string, unless the command line sets it. A field
  computed by a tag, a handlebars template or an environment map without
  that entry refuses the first AWS import before any AWS call, naming the
  field, the import, and the option that sets it. iidy-hs's wording is in
  the C17 card ("Sample refusal").
- A file without AWS imports may still compute these fields (Tavis,
  2026-11-17: keep this narrower rule rather than TypeScript's, which
  refuses computed fields always). Rust's current behaviour for such files
  is unchanged.
- The import configuration is built lazily at the first AWS import; a
  failure to build it is reported with its cause.

This card edits the Rust repository, =~/src/iidy/=, which is otherwise
read-only for this project. Tavis authorised that on 2026-11-17 for this
card.
